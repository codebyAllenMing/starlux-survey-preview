# STARLUX App 使用者問卷 — UX 研究專案

> 基於 626+ 則真實 App 評論的量化分析,設計用於驗證 5 大痛點的問卷。

🔗 **線上預覽**:https://codebyAllenMing.github.io/starlux-survey-preview/

---

## 專案脈絡

STARLUX 星宇航空以高端品牌建立實體服務口碑,但 App 在使用者端累積大量負評。
本專案以 UX 研究角度切入,目標:

1. 用真實評論(非憑空 persona)識別關鍵痛點
2. 透過量化問卷驗證痛點普遍性,補上評論抓不到的行為頻率
3. 產出 Journey Map 與訂票流程的優化提案

---

## 研究工作流

| Step | 內容 | 工具 |
|---|---|---|
| 1 | 抓 App Store + Google Play 公開評論(4 區域 626+ 則) | TypeScript + Bun |
| 2 | 主題 Cluster 分析(8 cluster,識別 5 大痛點) | Python |
| 3 | Journey Map 重構(以真實 pain points 取代憑空 persona) | Figma + MCP |
| 4 | **問卷設計**(本 repo 所在) | HTML 預覽 |
| 5 | 設計提案(待進行) | Figma |

---

## 5 大痛點(來自評論分析)

| Cluster | 平均星 | 概要 |
|---|---|---|
| 登入 / 驗證碼鏈卡關 | ★ 1.45 | 全 cluster 最低 |
| 訂票 / 付款當機 | ★ 1.83 | 量最大,會吃錢 |
| COSMILE 哩程消失 | ★ 1.96 | 主要打到常客 |
| App 內報到失敗 | ★ 2.15 | 逃到網頁,Stage 3 失能 |
| 客服制式回覆 | ★ 1.57 | 痛點放大器 |

## 問卷版本

| 版本 | 題數 | 時間 | 說明 |
|---|---|---|---|
| [v1.html](v1.html) | 10 | 5–7 min | 初版骨架,以 5 大痛點為對照基底 |
| [v2.html](v2.html) | 13 | 7–9 min | **推薦版**。補上純探索題、對手比較、雙軸打分、使用情境 |

### v1 → v2 進化重點

- ➕ **純探索題**(Q6)避免 confirmation bias
- ➕ **使用情境矩陣**(Q5)抓「在哪裡用」
- ➕ **雙軸打分**(Q11)品牌 vs App 分開,視覺化「品牌愛但 App 恨」
- ➕ **對手比較**(Q12)正反通道並陳 + 比較錨點
- 🔄 **訪談邀請上移**到 Q10 之後(高黏度點)
- 🔄 **開放收尾中性化**:「想罵髒話」→「印象最深」
